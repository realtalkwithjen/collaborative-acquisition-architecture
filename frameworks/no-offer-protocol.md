# Framework: The "No Offer" Protocol

## Definition
A disciplined deal screening process that teaches investors when to walk away before wasting time or capital.

## Components
- Pre-screening call triage
- Deal Analyzer Template application
- 50–65% conservative underwriting rule
- Owner finance exit alignment

## Function
Prevents beginners from pursuing deals that collapse under real-world friction.

## Application Context
Used during initial deal evaluation and coaching calls to filter motivated seller opportunities.

## What It Replaces
Hope-based math, desperate sales tactics, and guru-driven "just make an offer" advice.
